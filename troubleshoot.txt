```
Your backend logic (DB, APIs, S3, etc.)
```

A **504** means:

* Lambda was invoked
* But it **did not return a response in time**

---

# MOST COMMON ROOT CAUSES (90% cases)

I’ll list them **in order of probability** based on your error.

---

## 1️⃣ Backend is calling something that is NOT reachable

Examples:

* DynamoDB **outside AWS** (you mentioned this earlier)
* MongoDB / DB on private network
* Backend API with IP allowlist
* Corporate VPN dependency

### Why this causes 504

* Lambda tries to connect
* Connection hangs
* Lambda times out
* CloudFront returns 504

---

## 2️⃣ Lambda timeout is too low

Amplify API Lambdas have:

* **Default timeout ~10 seconds**
* Max allowed: **15 minutes** (but not enabled by default)

If backend query is slow → timeout.

---

## 3️⃣ Environment variables missing in Amplify

Very common.

Example:

* DB_HOST
* DB_PASSWORD
* API_BASE_URL

If missing:

* Code waits / retries
* Eventually times out

---

## 4️⃣ App worked earlier on EC2 / local but fails on Amplify

This usually means:

* Hardcoded `localhost`
* Private IPs
* Non-public DB endpoint
* Missing TLS config
